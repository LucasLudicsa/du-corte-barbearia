# Du Corte Barbearia

Site institucional da Du Corte Barbearia — Araraquara, SP.

Site estático (HTML/CSS/JS puro, sem build), com:

- Hero em vídeo
- Seção de serviços
- Galeria com fotos/vídeos reais da barbearia e lightbox
- Seção de contato com WhatsApp, Instagram e mapa

## Rodar localmente

Qualquer servidor estático funciona, por exemplo:

```bash
npx serve .
```
